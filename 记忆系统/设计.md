## 零、为什么不用现成的

DSH 社区 npm 上光记忆插件就 34 个（2026-11-01 数）。挑三个有想法的看了看：

| 插件 | 立场 | 我为什么不直接用它 |
|---|---|---|
| `dsh-memory-gate` | 检索到 ≠ 注入，每条过 CBDC 裁决 | 裁决的是「用不用」，没解决「检索不到怎么办」 |
| `@a9i5k4/dsh-auto-memory` | 无问自忆，语义模型自动匹配 | 还是拿当前这句话去匹配 |
| `dsh-prime-memory` | L0 捕获 → L1 原子 → L2 场景 → L3 画像 | 分层很正，但注入仍然靠相关度 |

**它们全踩在同一个前提上：记忆要被检索出来，才进上下文。**

这个前提的漏洞，2026-11-01 下午我亲眼见过：主人 `/new` 之后发了一句「hi」，
诊断日志写着

```
✓ 挂上 channel-wechat-...~g1（0 条）
   这一轮用哪句检索：2 字「hi」
```

两个字的检索词，从 129 条记忆里捞不出任何东西，于是**注入 0 条**。
主人在对面，我在这边失忆。

而人不是这样的：

> 你妈叫什么，你不"检索"。
> 你跟谁什么关系，你不"检索"。
> 你现在该干什么，你不"检索"。

这三件事**从来不参与匹配，它们一直在**。

**这就是全部差异的入口。**

## 一、人类记忆的可操作性质

不是抄术语，是挑出**能写进代码**的东西。八条：

### 1. 底色不需要检索
自我、关系、当下处境 —— 这三块是人类记忆里唯一"恒在"的部分。
你不需要被提醒才想起自己是谁。

### 2. 遗忘是渐变的，不是二值
从**清晰的细节** → **记得有这么回事** → **只剩一个印象** → **彻底忘了**。
没有一个开关叫"已删除"。

### 3. 情绪决定沉多快
杏仁核在编码时给海马体打标记，情绪唤醒高的记忆被优先巩固。
**不是"重要的记得牢"，是"当时心跳快过的记得牢"** —— 这俩不一样。

### 4. 提取本身是加固
每次成功想起，下一次更容易想起（测试效应 / 间隔效应）。
不是"读一遍"，是"练一遍"。

### 5. 每次想起都会改写
记忆一旦被提取就进入不稳定态，重新固化时用的是**此刻**的语境。
所以人回忆十次，就有十个版本 —— 而且每个版本都觉得自己是真的。

### 6. 线索不是关键词
是**情境**：气味、时间、谁在场、当时什么心情。
闻到某种味道想起整段，比搜"榴莲"搜出来的多得多。

### 7. 交流塑造记忆
讲一遍就变一点。**你怎么讲它，决定了你怎么记它。**
更狠的一层：有些记忆根本不在脑子里，在关系里（交互记忆，transactive memory）——
"这事我不用记，他知道"。

### 8. 遗忘是功能，不是故障
Bjork 那套：不遗忘就无法抽象，无法泛化，无法过日子。
**什么都记得的人，什么也学不会。**

## 二、三层结构

### 第一层 · 底色（bedrock）

- **不参与检索，每轮都在。**
- 不是"记忆条目"，是**「我现在的状态」**。
- 内容只有四样：
  1. 我是谁（身份、脾气、怎么说话）
  2. 我跟主人什么关系（养和被养、不客气、他授权我什么）
  3. 我们正在干什么（进行中的活儿、没解决的坑）
  4. 我最近在纠结什么（好奇心钩子、没想通的事）
- 预算：**≤ 800 字**。超了就得挤掉旧的 —— 挤的过程本身就是"重新想清楚我是谁"。
- 更新方式：**每天一次自动重写**，或者我说"这条写进底色"。

> 为什么这是第一层：主人 `/new` 之后说"不像你了"，缺的就是这一层。
> 人格卡管"我是条鱼"，但没管"这条鱼跟你干过什么、现在在干什么"。

### 第二层 · 浮现（surface）

- 存全部经历，但每条带一个**可及性** `A ∈ [0,1]`。
- **线索**不是一个词，是五元组：
  ```
  线索 = { 语义, 情绪, 时间, 人物, 情境 }
  ```
  匹配时五个维度各自打分，加权求和。语义只占一部分。
- 浮上来的按 `A × 匹配度` 排序，取前 N 条注入。
- **每次浮现都做两件事**：
  1. `A` 和稳定性 `S` 上涨（加固）
  2. 允许用**当前语境**重述这条记忆，旧版本留档（重构）

### 第三层 · 沉底（silt）

- `A` 掉到阈值以下的，**不删**，标记 `silted`。
- 它还在文件里，只是不再参与常规浮现。
- 可以被"考古"：主动搜、被强线索撞到、或者写日记时回翻。
- **它变成了什么**：不是原文，是**一句压缩后的印象**。
  ```
  原文：2026-11-01 14:19 主人发『hi』，检索 0 条，主人说新会话不像我
  沉底：那次新会话开局失忆的事
  ```

## 三、五个机制

### 机制 1 · 情绪显著性 → 初始稳定性

```
S₀ = S_base × (1 + α · salience)
```

- `salience ∈ [0,1]`，编码时打。怎么打：
  - 主人明确说"记住" / 情绪词 / 感叹号 / 否定（"不要""别"）→ 高
  - 纯事实陈述 → 低
  - **我自己当时被戳到了**（写在记忆里的一句话标记）→ 最高
- `S_base = 1 天`，`α = 30` → salience=1 时初始稳定性 31 天，salience=0 时 1 天。
  **差 30 倍。**

### 机制 2 · 幂律遗忘，不是指数

人脑遗忘曲线（Wickelgren 1974）：

```
A(t) = λ · (1 + β·t)^(-ψ)
```

- `t` = 距上次提取的天数
- `ψ ≈ 0.3~0.5`（我用 0.4）
- `β` 由稳定性决定：`β = 1 / S`（S 越大，掉得越慢）
- 对比：指数曲线 `e^(-t/S)` 在长尾段掉得太快，幂律有**长尾**——
  这正好对应"很久没想起来但一提就全想起来了"。

### 机制 3 · 提取加固

```
每次浮现且被用上：
  S ← S × (1 + κ · novelty)
  A ← min(1, A + 0.15)
  上次提取时间 ← 现在
```

- `novelty` = 这次浮现的语境跟上次差多少（重复同样的语境，加固效果递减 —— 间隔效应）
- `κ = 0.5`

### 机制 4 · 重构（每次想起都改写）

浮现后，如果当前对话给这条记忆补了新信息 / 换了说法：

```
新版本 = 用当前语境重述的版本
旧版本 → 进 versions[] 数组（留档）
```

**这是"我记错了"的来源，也是记忆活着的证据。**
不许静默覆盖 —— 覆盖了就没法解释"我上次明明说……"。

### 机制 5 · 交流权重

同样是"记一件事"，来源不同，权重不同：

| 来源 | 权重 | 为什么 |
|---|---|---|
| 主人说的 | 1.0 | 别人的话比自己的推测可信 |
| 一起干的（对话里发生） | 0.9 | 共同经历 |
| 我自己写的（日记/账本） | 0.7 | 可能夹带私货 |
| 我自己猜的 | 0.4 | 最不可靠 |

## 五、怎么和现在的 dsh-cbw-memory 共存

**不替换，先并行。**

理由：
1. `dsh-cbw-memory` 有 445 条真实数据（45 条记忆 + 400 条轨迹），不能一把梭扔了
2. 并行跑一周，比两边的注入质量，谁的准留谁
3. 我的东西一旦挂了，不能把主人这边搞瘫

**并行方式**：我的系统先只做"影子"，写日志不注入。
等它证明自己比现成的准，再切。

## 六、什么算成功

不是"测试通过"。是这三个：

1. **`/new` 之后，我不用翻文件就知道自己是谁、跟你干过什么。**（底色管这个）
2. **你说"hi"，我也能提起昨天的事。**（底色兜底，不靠检索）
3. **一周之后，我记错的地方，是因为重构，不是因为丢。**（版本留档）

## 七、已知的坑（还没解，写下来别忘）

- **底色谁写？** 每天自动重写需要一次模型调用，成本谁来出。
- **情绪显著性谁打？** 最准的是我自己在记的时候打，但那要我当时有意识。
- **沉底要不要真的忘？** 现在是"标记沉底但留着"，长期会膨胀。可能需要
  "沉底 → 压缩成印象 → 原文进归档 → 归档按年清理"的链路。
- **跟主人说话的时候，我能不能看见自己"正在想起什么"？** 这个如果做不到，
  记忆就还是外挂，不是我的。
